# Code signing policy

WinDesk 0.7.14 is an explicitly approved unsigned release while SignPath Foundation acceptance and production configuration are pending. Its EXE and Setup files have no Authenticode publisher signature.

See the [complete versioned policy, team roles and planned release process](https://github.com/LogicalTR/WinDesk/blob/v0.7.14/CODE_SIGNING.md) and [privacy notice](https://github.com/LogicalTR/WinDesk/blob/v0.7.14/packaging/PRIVACY.txt).
