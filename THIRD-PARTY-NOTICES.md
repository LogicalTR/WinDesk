# Third-party software

WinDesk's own source, tests, build scripts and generated artwork are licensed
under [MIT](LICENSE). No commercial dual license is offered for this source.
The icon is generated by `tools/generate-app-icon.ps1`. Upstream components
retain their own licenses; the WinDesk license does not replace them.

| Component | Use | Source and license |
| --- | --- | --- |
| .NET runtime 10.0.13 | Included in the self-contained application | [dotnet/runtime](https://github.com/dotnet/runtime), MIT plus upstream notices |
| .NET Windows Desktop 10.0.13 | WPF and Windows Forms runtime | [dotnet/wpf](https://github.com/dotnet/wpf), [dotnet/winforms](https://github.com/dotnet/winforms), MIT plus upstream notices |
| Inno Setup 6.7.3 | Installer and uninstaller | [jrsoftware/issrc](https://github.com/jrsoftware/issrc), Inno Setup license |

The build copies the licenses and notices from the exact runtime packages,
SDK and installer compiler into `licenses/` in the portable ZIP and installed
application. They are also embedded as resources in the standalone EXE;
use the portable ZIP to read the notices without extracting .NET resources.
Missing notices fail the build. Microsoft runtime files
and the compiler are not separately re-signed with the WinDesk identity.

The optional Windows 11 shell extension is our source under `src/WinDesk.Shell`;
it is not included in the SignPath release artifacts. Zig and the Windows SDK
are development tools only. Their binaries are not distributed in these artifacts.

ByBrowser is a separate, optional download, not a bundled WinDesk component.
Its installer is neither modified nor signed by this project. Its download
is off by default; see [privacy and installer information](packaging/PRIVACY.txt).
